# 中国真实事件海龟汤·五维多元玩法500题全景档案 (Ver 2.0)

> **设计宗旨**：彻底摆脱传统海龟汤单一的“凶杀验尸/调查死因”套路，还原情境推理（Lateral Thinking Puzzle）的丰富玩法维度。
> **两大铁律**：
> 1. **100% 真实背景**：取材于中国救援实录、经侦打假公案、社会奇特民生新闻、隐蔽战线解密档案、时代感人真情。
> 2. **拒绝反逻辑与虚假浮夸**：绝无超自然神力，绝无违背物理常识与人类常理的“抗日神剧式”假大空。所有解密全部遵循硬核科学、心理学、金融规则与现实逻辑。

## 🎮 角色扮演玩法（非验尸模式指引）

在已配置好的 `roleplay` 技能下，玩家可选择以下沉浸式角色：
1. **救援指挥调度员**（对接【红汤】）：根据被困者断断续续的敲击信号或现场地形图，指导被困人员自救脱困。
2. **特聘独立审计师 / 经侦探长**（对接【金汤】）：面对一堆相互矛盾的商业报表与高管口供，揪出商海老千。
3. **金牌民警 / 民生调解员**（对接【灰汤】）：抽丝剥茧还原让人啼笑皆非的真实乌龙真相。
4. **隐蔽战线情报分析员**（对接【绿汤】）：根据截获的生活物资采购单或茶馆暗号，推导敌特潜伏路线或传递路线。
5. **寻访记者 / 档案解密员**（对接【白汤】）：探寻三十年前某位普通人反常举动背后震撼人心的默默守护。
