## 网页界面与组件库

当前界面使用 **Next.js + React 18 + CandyUI**。按钮、输入框、多行文本、选择器、卡片、面板、列表、徽章、进度条、弹窗和通知均由 CandyUI 提供；操作图标统一使用 `CandyGameIcon`，不再使用裁剪 PNG 图标、emoji 或自绘 SVG。吉祥物、头像和品牌插画保留。应用 CSS 仅负责布局、背景与响应式，不覆盖组件库皮肤。

在项目根目录安装 GitHub 依赖：

```powershell
bun add github:deadmau5v/CandyUI
bun dev
```

依赖声明是 `"candy-ui": "github:deadmau5v/CandyUI"`，`bun.lock` 锁定具体 commit，普通 `bun install` 会复现锁定版本而不是自动获取新提交。上游更新后显式更新 CandyUI，再运行类型检查和 Vitest。库仓库需要包含可使用的 dist 构建产物。

默认游戏入口与 API 均为 http://localhost:3001。开发模式下 Next.js 重编译页面，刷新该地址查看更新。`web/src/App.tsx` 保留为兼容 SPA，现有 `build` 脚本仍验证 Vite 兼容入口；不要将其当作 Next.js 生产构建。

## 🎮 Windows PowerShell 运行指南

### 1. 启动多人联机 Web 游戏
进入项目根目录，设置 Node 与 pnpm 环境变量后启动服务：

```powershell
$NODE = "C:\Users\d5v\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
$PNPM = "C:\Users\d5v\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\pnpm\bin\pnpm.mjs"
$env:PATH = "$(Split-Path $NODE);$env:PATH"
& $NODE $PNPM dev
```

- **开发前端**：http://localhost:5173  
- **后端 API 与 Socket.IO**：http://localhost:3001  
- **题库加载机制**：系统已自动载入 `data/puzzles.json` 和 `turtle.db`，所有 1,105 道海龟汤均可在前端房间内自由创建与抽选！

### 2. 数据库快速核验
可直接通过 Python 快速检验本地数据库与题库容量：

```powershell
$PY = "C:\Users\d5v\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $PY -c "import sqlite3; conn = sqlite3.connect('turtle.db'); print('当前题库收录总数:', conn.cursor().execute('SELECT count(*) FROM puzzles').fetchone()[0])"
```

### 3. 使用 `roleplay` 技能进行桌面互动主持
若在 DSH 命令行或终端环境中游玩，系统已全局激活 `roleplay` 技能：
- **DM裁判问答模式**：系统担任主持人，只回答【是】/【不是】/【不相关】/【是，但非关键】；
- **实境破案/救援推演模式**：玩家扮演现场刑警、审计师、救援指挥官或特工，下达交互勘查指令，由系统根据真实案卷动态推进剧情。
