# 海龟汤多人联机版 (Turtle Soup Online)

> **版本**：v2.0 (经典精编版)  
> **底层技术栈**：Node 24 + TypeScript (ESM) + Express 5 + Socket.IO 4 + React 18 + Next.js App Router + CandyUI + SQLite (WAL)  
> **题库容量**：**105 道开源精选经典海龟汤**（精简、反转、耐玩，杜绝冗长晦涩的工业/事故报告）

---

## 📚 精选题库一览

收录最经典的经典海龟汤：
- 《灯塔看守员》、《海龟汤》、《酒保的枪》、《半瓶香水》、《一巴掌》、《天窗》、《盲人喝水》、《水草》、《盲人的狗》、《绿色的衣服》、《葬礼上的偶遇》、《牛吃草》等 105 道精编经典情境推理剧本。
- 每道题目均经过规范化清洗，具备明晰的【汤面】与【汤底】，符合海龟汤核心玩法：短小精悍、反差强烈、逻辑闭环。

---

## 🎮 核心机制

1. **多人实时联机**：支持房间码一键创建与邀请，多人实时加入。
2. **AI 主持人（JEV 裁判）**：
   - 提问判定：AI 依据谜题汤底回答「**是**」、「**不是**」、「**不相关**」或「**不确定**」。
   - 案情还原：判断玩家案情猜测是否「**破解成功**」、「**接近真相**」或「**还没猜对**」。
3. **轮次与配额**：每人默认 8 次提问机会，可切换共享额度；所有玩家额度用尽自动揭晓汤底。
4. **CandyUI 游戏视觉**：采用 CandyUI 游戏组件库，沉浸式对战界面。

---

## 🚀 启动与运行

### 生产环境（Mac / Linux）
```bash
./scripts/start-daemon.sh   # 后台启动守护进程（PORT: 3001）
./scripts/status.sh         # 查看运行状态与健康检查
./scripts/stop-daemon.sh    # 停止服务
```

### 开发环境
```bash
pnpm dev
# 或在 Windows PowerShell:
bun dev
```

- **访问地址**：http://localhost:3001 或线上绑定的 http://turtle.d5v.cc/
